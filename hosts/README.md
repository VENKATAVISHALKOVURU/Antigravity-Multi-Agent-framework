# ag-stack Host Adapters

ag-stack works in any AI coding tool. Here is how to activate it in each:

## AntiGravity
Copy `ANTIGRAVITY.md` to your project root. AntiGravity loads it automatically.

## Claude Code  
Copy `ANTIGRAVITY.md` as `CLAUDE.md` in your project root.

## Cursor
Copy contents of `ANTIGRAVITY.md` into `.cursorrules` in your project root.

## Windsurf
Add `ANTIGRAVITY.md` to your project context files.

## GitHub Copilot
Add to your custom instructions in VS Code settings.

## Any tool
The core is plain Markdown. If your tool reads a context file at session start,
drop ANTIGRAVITY.md there and the team activates.
